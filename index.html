    😴 Somn – ultimele 7 zile

    🛠️ Cum conectez Apple Watch? (configurare o singură dată)

    Aplicațiile web nu pot citi direct din Sănătate, așa că folosim o Scurtătură (aplicația Scurtături / Shortcuts, deja instalată pe iPhone). Ea adună datele zilei și le copiază; FitJurnal le preia cu butonul de mai sus.

    Numele acțiunilor pot diferi puțin în română. Caută-le după cuvintele din paranteză în bara de căutare a acțiunilor.

    1. Creează scurtătura

    1. Deschide Scurtături → + → numește-o FitJurnal Sync.

    2. Pași (la fel pentru kcal, distanță, minute de exercițiu, etaje)

    1. Adaugă Găsește eșantioane de sănătate (Find Health Samples).
    2. Filtru: Tip este Pași, Data de început este astăzi.
    3. Adaugă Calculează statistici (Calculate Statistics) → Sumă.
    4. Adaugă Setează variabila (Set Variable) → numele Pasi.

    Repetă blocul de mai sus pentru:

    • Energie activă (Active Energy) → variabila KcalActive
    • Energie în repaus (Resting Energy) → KcalRepaus
    • Distanță mers + alergare (Walking + Running Distance) → Distanta (alege unitatea km)
    • Minute de exercițiu (Exercise Minutes) → Exercitiu
    • Etaje urcate (Flights Climbed) → Etaje

    3. Puls

    1. Găsește eșantioane de sănătate: Tip Puls în repaus (Resting Heart Rate), data de început astăzi, sortează după Data de început, Cele mai noi primele, limită 1 → variabila PulsRepaus.
    2. Opțional: Tip Puls (Heart Rate), astăzi → Calculează statistici → Medie → variabila PulsMediu.

    4. Somn

    1. Găsește eșantioane de sănătate: Tip Analiză somn (Sleep Analysis), Data de sfârșit este astăzi, Valoare nu este În pat și nu este Treaz, Sursa este Apple Watch-ul tău (ca să nu se dubleze cu iPhone-ul).
    2. Repetă cu fiecare (Repeat with Each) → în interior Obține timpul dintre date (Get Time Between Dates): de la Data de început a elementului până la Data de sfârșit, în minute.
    3. După buclă: Calculează statistici → Sumă pe Rezultatele repetării → variabila Somn.

    5. Antrenamente (opțional)

    1. Găsește eșantioane de sănătate: Tip Antrenamente (Workouts), data de început astăzi.
    2. Repetă cu fiecare → Text: antrenament=[Tip];[Durată];[Energie activă] (inserează câmpurile elementului repetat).
    3. După buclă: Combină textul (Combine Text) cu Linie nouă → variabila Antrenamente.

    6. Textul final

    1. Formatează data (Format Date): Data curentă, format personalizat yyyy-MM-dd.
    2. Adaugă Text și scrie exact (inserând variabilele în locul parantezelor):
    FITJURNAL
data=[Data formatată]
pasi=[Pasi]
kcal_active=[KcalActive]
kcal_repaus=[KcalRepaus]
distanta_km=[Distanta]
exercitiu_min=[Exercitiu]
etaje=[Etaje]
puls_repaus=[PulsRepaus]
puls_mediu=[PulsMediu]
somn_min=[Somn]
[Antrenamente]
    1. Adaugă Copiază în clipboard (Copy to Clipboard).
    2. Adaugă Deschide aplicația sau o notificare „Gata, deschide FitJurnal”.

    7. Folosire

    1. Rulează FitJurnal Sync (prima dată iPhone-ul cere acces la Sănătate → Permite).
    2. Deschide FitJurnal → Sănătate → 📋 Importă din Sănătate → Lipește.
    3. Poți rula oricând în timpul zilei: datele zilei se actualizează, nu se dublează.

    Sfat: în Scurtături → Automatizare poți porni scurtătura automat în fiecare seară. Poți pune scurtătura și ca widget pe ecran.
