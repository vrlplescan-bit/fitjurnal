        🛠️ Cum conectez Apple Watch? (configurare o singură dată)

        Aplicațiile web nu pot citi direct din Sănătate. O Scurtătură iPhone citește datele zilei și le scrie într-un Gist secret din contul tău GitHub (câte un fișier pe zi). FitJurnal le preia singură când o deschizi.

        1. Cheia GitHub

        1. Deschide github.com/settings/personal-access-tokens/new.
        2. Nume FitJurnal Shortcut, la Account permissions → Gists alege Read and write, apoi Generate token și copiaz-o.

        2. Scurtătura

        1. Citește din Sănătate (cu Find Health Samples + Calculate Statistics): pași, energie activă și în repaus, distanță, minute de exercițiu, etaje, puls în repaus și mediu, somn.
        2. Construiește un Text:
        FITJURNAL
data=[data, format yyyy-MM-dd]
pasi=[...]
kcal_active=[...]
kcal_repaus=[...]
distanta_km=[...]
exercitiu_min=[...]
etaje=[...]
puls_repaus=[...]
puls_mediu=[...]
somn_min=[...]
antrenament=Tip;minute;kcal   (opțional, câte unul pe linie)
        1. Get Contents of URL: https://api.github.com/gists/ID_GIST, metoda PATCH, header Authorization: Bearer CHEIA, corp JSON files → [data].txt → content = Text.

        3. Permisiuni iPhone

        1. Sănătate → poza de profil → Confidențialitate → Aplicații → Scurtături → Activează tot.
        2. Configurări → Aplicații → Scurtături → Avansat → Permite partajarea unor cantități mari de date.
        3. La prima rulare: Always Allow pentru trimiterea către api.github.com.

        4. Conectare și automatizare

        1. Lipește linkul Gist-ului mai sus și apasă Conectează.
        2. În Scurtături → Automatizare → Ora din zi (ex. 21:00, zilnic) → Rulează imediat → alege scurtătura.
